# NutriEduc — Funcionalidades

## Área de Profissionais — Nutrição

**Funcionalidades:**

- Editar cadastro dos alunos
- Cadastrar e gerenciar tipos de restrições alimentares
- Cadastrar alergias alimentares
- Visualizar histórico de restrições/alergias do aluno
- Cadastrar alimentos
- Editar alimentos
- Desativar alimentos
- Pesquisar alimentos
- Categorizar alimentos
- Cadastrar composição nutricional dos alimentos
- Informar valores nutricionais dos alimentos
- Cadastrar alergênicos dos alimentos
- Relacionar alimentos às restrições alimentares
- Definir alimentos permitidos/não permitidos
- Definir parâmetros utilizados na geração automática dos cardápios
- Alterar parâmetros de geração dos cardápios
- Criar cardápios manualmente
- Editar cardápios
- Excluir/cancelar cardápios
- Visualizar cardápios
- Duplicar cardápios existentes
- Definir período de validade do cardápio
- Definir refeições do dia
- Adicionar alimentos às refeições
- Remover alimentos das refeições
- Calcular valores nutricionais do cardápio
- Gerar cardápios automaticamente a partir de valores de parâmetro
- Verificar compatibilidade dos alimentos com as restrições dos alunos
- Separar alimentos prejudiciais ou não
- Identificar alimentos incompatíveis com alergias/restrições
- Alertar quando um cardápio possuir alimento incompatível
- Visualizar histórico de cardápios
- Aprovar/publicar cardápios
- Alterar cardápios já publicados
- Gerar relatórios
- Gerar tabelas já formatadas
- Exportar relatórios em PDF
- Exportar relatórios em Excel
- Exportar relatórios em Word

- Consultar restrições alimentares dos alunos
- Consultar alergias dos alunos
- Consultar informações necessárias para preparo das refeições
- Verificar cardápios
- Verificar cardápios por dia
- Verificar cardápios por refeição
- Verificar histórico de cardápios
- Visualizar alterações realizadas nos cardápios
- Receber atualizações de cardápios
- Criar relatórios de ocorrências
- Registrar ocorrência relacionada a aluno
- Registrar ocorrência relacionada a refeição
- Registrar ocorrência relacionada a alimento
- Visualizar ocorrências registradas
- Acompanhar status das ocorrências
- Solicitar mudanças nos cardápios
- Acompanhar solicitações de mudança
- Solicitar ingredientes
- Informar falta de ingredientes
- Acompanhar solicitações de ingredientes
- Enviar feedback
- Visualizar respostas/retornos das solicitações
- Receber notificações de alterações ou solicitações

## Área pública — Pais

**Regras de negócio:** os pais só podem ver os cardápios livremente, as ocorrências e solicitações só podem ser feitas para os alunos os quais eles são responsáveis, o cadastro também é feito pelos profissionais das escolas.

**Funcionalidades:**

- Verificar os cardápios
- Pesquisar cardápios
- Filtrar cardápios por escola/unidade
- Verificar cardápio por dia
- Verificar cardápio por refeição
- Visualizar informações dos alimentos
- Visualizar informações nutricionais disponibilizadas
- Verificar ocorrências dos seus alunos
- Relatar ocorrências
- Consultar histórico de ocorrências dos seus alunos
- Solicitar a inclusão de alergias
- Solicitar alteração de restrição alimentar
- Acompanhar solicitações realizadas
- Visualizar status das solicitações
- Enviar feedback
- Visualizar retorno dos feedbacks
- Receber notificações sobre alterações relevantes no cadastro do aluno
- Visualizar alunos vinculados ao responsável
